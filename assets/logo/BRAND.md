# Gnomon brand assets

**Mark — "sliced gnomon".** A gnomon is the blade of a sundial, the edge whose
shadow tells time. The blade is cut into planner rows (spans on the time axis);
in the third row a short, lower-priority job (teal) is backfilled into the gap
without delaying anything above it.

| File | Use |
|---|---|
| `svg/gnomon-lockup-light.svg` / `-dark.svg` | Primary horizontal logo (README, docs, site header) |
| `svg/gnomon-lockup-stacked.svg` | Square-ish placements |
| `svg/gnomon-icon-dark.svg` / `-light.svg` | App icon / avatar tile |
| `svg/gnomon-mark*.svg` | Mark alone: full colour, on-dark (`-white`), one-colour (`-mono`) |
| `svg/gnomon-wordmark-mono.svg` | CLI / terminal contexts |
| `png/gnomon-icon-{16..1024}.png`, `favicon.ico` | Raster exports |

All SVG text is outlined; no fonts required to render.

**Colours** — Ink `#0B1220` · Signal Teal `#14B8A6` · Teal Light `#5EEAD4` (on dark) ·
Slate `#1E293B` · Paper `#F8FAFC`.

**Type** — Wordmark: Space Grotesk 600, −2% tracking, lowercase.
CLI/docs: JetBrains Mono 500. Both SIL OFL.

Keep clear space of at least one row height (8/64 of the mark) around the mark;
don't recolour the backfilled span to anything but the accent.
